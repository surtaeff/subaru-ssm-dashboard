# Цветной экран по USB (ESP32-S3)

Отдельное USB-устройство рядом с кабелем ЭБУ и платой датчиков: плата на ESP32-S3 со своим AMOLED или IPS экраном.
Приложение само рисует страницы (те же дизайны стрелок, что на карточках, плитки, крупную цифру, список) с любыми
значениями: ЭБУ, коробка, поездка, GPS, датчики SensorBox, параметры с вкладки «Датчики». На экран уходят только
изменившиеся куски, плата их только выводит. Новый вид не требует новой прошивки.

Настройки, вкладка «Цветной экран»: выбор платы, прошивка с магнитолы, поворот, яркость, страницы, смена страниц
(кнопка BOOT на плате, по времени), показ тревоги (значение за пределом нормы открывает свою страницу).

## Большие экраны (bigscreen/)

Отдельный скетч `bigscreen/bigscreen.ino`, платы в `bigscreen/big_boards.h`, сборка `bigscreen/build-big.sh`, файлы
`bin/usbscreen-<id>.bin` и `bin/manifest-big.json`. Прошивка маленьких плат от него не зависит и не менялась.

| id | Плата | Экран | Кабель | Кадров/с (оценка) | Прошивка |
|---|---|---|---|---|---|
| ws_s3_lcd_43 | Waveshare ESP32-S3-Touch-LCD-4.3 | 800×480 RGB | порт USB | 10 | с магнитолы |
| ws_s3_lcd_5 | Waveshare ESP32-S3-Touch-LCD-5 (не 5B) | 800×480 RGB, питание 7-36 В | порт USB | 10 | с магнитолы |
| ws_s3_lcd_7 | Waveshare ESP32-S3-Touch-LCD-7 | 800×480 RGB | порт USB | 10 | с магнитолы |
| ws_p4_7b | Waveshare ESP32-P4-WIFI6-Touch-LCD-7B | 1024×600 MIPI-DSI | порт USB 1.1 FS | 15 | с компьютера |
| ws_p4_101 | Waveshare ESP32-P4-WIFI6-Touch-LCD-10.1 | 800×1280 MIPI-DSI | порт USB OTG | 20 | с компьютера |

Ни одна из этих плат не была в руках: прошивки собраны, на железе не запускались. Источник каждого пина записан в big_boards.h.
Кадры посчитаны, а не измерены: при смене значений уходит 0-21 КБ, смена страницы 33-114 КБ в JPEG, при 500 КБ/с.

В отличие от маленьких, на большом экране можно выбрать страницу «Моя Главная», «Моя Динамика», «Мой экран» или
«Спорт-дисплей»: это ваше расположение из приложения в родном разрешении панели, и своё оформление. Графики идут числом,
3D, карта и другие особые карточки остаются пустыми. Кнопки страниц нет (на S3 GPIO0 занят экраном): страницы по времени.

Платы ESP32-P4 прошиваются с компьютера через порт USB TO UART:
`esptool write-flash 0 usbscreen-ws_p4_7b.bin` для чипа ревизии 3.00 и новее, файл `-pre3` для более старых (esptool показывает
ревизию при подключении). На USB OTG и USB FS такие прошивки работают с приложением как обычно.

К протоколу добавлено: в ответе на `?` поля `maxpx=<N>` и `jpeg=1`; команда `J <x> <y> <w> <h> <n>` и n байт JPEG ровно w×h,
ответ `K` или `E`; прямоугольник до 131072 точек. Старая прошивка этих полей не шлёт и получает прежний обмен.

## Протокол

USB самой ESP32-S3 (Hardware CDC and JTAG, 303A:1001), строки до `\n`.

| Кто | Строка | Смысл |
|---|---|---|
| приложение | `?` | кто ты → `I USBSCREEN 1 board=<id> w=<W> h=<H> round=<0\|1> fw=<N> id=<MAC>` (по id у каждого экрана свои настройки) |
| приложение | `P <x> <y> <w> <h> <n>` и n байт | прямоугольник (до 16384 точек, края чётные), точки построчно в RGB565 little-endian, упакованы: байт h, при h & 0x80 повтор (h & 0x7F) + 1 точек одного цвета (2 байта), иначе h + 1 точек как есть; ответ `K` или `E` |
| приложение | `B <0..255>` | яркость |
| приложение | `Z` / `H` | чёрный экран / «я на связи» |
| экран | `N` / `L` | кнопка BOOT коротко / долго: следующая страница |
| экран | `Y R` | 5 с не было строк (на экране NO LINK), прислать всё заново |

## Прошивка

С магнитолы: кнопка «Прошить экран». Приложение переводит ESP32-S3 в загрузчик ROM линиями DTR/RTS (как esptool),
пишет склеенный образ с адреса 0 блоками по 1 КБ и сверяет MD5. Загрузчик в ПЗУ, испортить его нельзя. Новая плата с
чужой прошивкой может не перейти в загрузчик сама: зажать BOOT, вставить USB или нажать RST, отпустить BOOT.

Пересобрать после правки: `./build-bin.sh` (нужен `arduino-cli`, ставит пакет esp32 3.3.10 и Arduino_GFX 1.6.9).
Скрипт пишет `bin/usbscreen-<id>.bin` и `bin/manifest.json`; юнит-тест не даст выпустить приложение со старыми файлами.
